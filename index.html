Projet

Enregistre la vidéo, le log, le son ajouté, la synchronisation, les coupes et les jauges dans un seul fichier .otproj pour reprendre l'édition plus tard.

Disposition des jauges

Enregistre uniquement la position et la taille des jauges dans un fichier .json, pour les replacer à l'identique sur une autre vidéo.

1. Fichiers

      Mixé avec le son d'origine. Le départ est compté sur la vidéo exportée, après les coupes. Glisse une piste sur la frise sous la vidéo pour la placer, ou « ⤓ Ici » pour la caler sur l'instant affiché. Sur la forme d'onde : clic pour choisir où écouter, glisser pour sélectionner un passage à couper ou à garder.

      2. Synchronisation

      Mets la vidéo sur un instant reconnaissable (décollage, coup de gaz), clique sur Marquer, puis clique sur le même instant dans la courbe du log.

      4. Export

      Les vidéos MP4, MOV et AVI sont traitées image par image, plus vite que la lecture, même si l'onglet passe en arrière-plan. Les autres formats passent par un export en temps réel.

      Export lent, carte graphique à 0 % ?

      Sur un PC portable, Windows fait souvent tourner le navigateur sur la puce graphique intégrée (Intel / AMD) : la carte graphique dédiée (NVIDIA / AMD) reste à 0 % pendant l'export. Pour la lui confier : Paramètres Windows › Système › Affichage › Graphiques, choisis le navigateur (Chrome ou Edge), règle-le sur Hautes performances, puis ferme et relance le navigateur. Branche aussi le PC sur secteur : sur batterie, Windows bride le navigateur (mode efficacité).

      Le centre de l'image est gardé (zone claire dans l'aperçu) et les jauges sont replacées dans le cadre vertical. Pour un extrait court, garde le meilleur passage :

      Une image PNG par trame, à la cadence de la vidéo, avec les jauges sur fond transparent. Les images sont regroupées dans une archive ZIP : décompresse-la avant de l'importer. Dans le logiciel de montage, importe la séquence et pose-la sur une piste au-dessus de la vidéo. Les jauges étant dessinées, elles restent nettes en 4K même depuis une vidéo HD.
