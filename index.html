Installer l’application

  1. Touche le bouton Partager de Safari (carré avec une flèche vers le haut).
  2. Choisis Sur l’écran d’accueil.
  3. Touche Ajouter : l’application s’ouvre ensuite depuis son icône, en plein écran.

Analyzer

Courbes du log par-dessus la vidéo, pour étudier le vol. Dans la fenêtre : molette pour zoomer, glisser pour se déplacer, Maj + glisser pour sélectionner un passage ; ses bords et ses coins la redimensionnent.

Analyses

Données du log

Formules

Données calculées, utilisables dans toutes les analyses : données entre accolades, par exemple {setpoint[0]} - {gyroADC[0]} ou {RxBt} * {Curr}. Opérations + − × ÷ ^, comparaisons (1 ou 0), fonctions abs, min, max, sqrt, pow, hypot, atan2, round…

Projet

Enregistre la vidéo, le log, le son ajouté, la synchronisation, les coupes et les jauges dans un seul fichier .otproj pour reprendre l'édition plus tard.

Disposition des jauges

Enregistre uniquement la position et la taille des jauges dans un fichier .json, pour les replacer à l'identique sur une autre vidéo.

1. Fichiers

        Mixé avec le son d'origine. Le départ est compté sur la vidéo exportée, après les coupes. Glisse une piste sur la frise sous la vidéo pour la placer, ou « ⤓ Ici » pour la caler sur l'instant affiché. Sur la forme d'onde : clic pour choisir où écouter, glisser pour sélectionner un passage à couper ou à garder.

        2. Synchronisation

        Mets la vidéo sur un instant reconnaissable (décollage, coup de gaz), clique sur Marquer, puis clique sur le même instant dans la courbe du log.

        Police

        Marqueurs / chapitres

        Aucun marqueur. Pose-en avec ◆ Marqueur ici (touche M) sous la frise, ou ✨ Proposer depuis le log.

          Exporter

          Temps de la vidéo exportée (passages coupés retirés). Les chapitres sont aussi inscrits dans le MP4 de l'export rapide (VLC, mpv).

          Annotations

          Textes, émojis et flèches affichés quelques secondes sur la vidéo, pour faire ressortir une valeur, réagir ou expliquer. Glisse-les dans l'aperçu (et la pointe de la flèche), tire un coin ou utilise la molette pour la taille, Suppr pour retirer.

          Aucune annotation. Pose-en une avec 💬 Annotation ici (touche N), ici ou sous la frise.

            4. Export

            Les vidéos MP4, MOV et AVI sont traitées image par image, plus vite que la lecture, même si l'onglet passe en arrière-plan. Les autres formats passent par un export en temps réel.

            Export lent, carte graphique à 0 % ?

            Sur un PC portable, Windows fait souvent tourner le navigateur sur la puce graphique intégrée (Intel / AMD) : la carte graphique dédiée (NVIDIA / AMD) reste à 0 % pendant l'export. Pour la lui confier : Paramètres Windows › Système › Affichage › Graphiques, choisis le navigateur (Chrome ou Edge), règle-le sur Hautes performances, puis ferme et relance le navigateur. Branche aussi le PC sur secteur : sur batterie, Windows bride le navigateur (mode efficacité).

            ✂ Montage automatique Expérimental

            Repère les moments forts (vitesse, figures, rase-mottes, tours, son, mouvement de l'image) et ne garde qu'eux, avec des raccords placés sur des instants calmes et, à partir de 30 s, une ouverture sur le décollage et une fin sur l'atterrissage. Les coupes apparaissent sous la vidéo : tu peux les ajuster avant d'exporter.

            Aucune vidéo chargée : l'export dessine les jauges sur toute la durée du log, à 30 images par seconde. Le fond vert se retire dans un logiciel de montage (incrustation / chroma key) ; pour un calque transparent, choisis la séquence PNG.

            Le centre de l'image est gardé (zone claire dans l'aperçu) et les jauges sont replacées dans le cadre vertical. Pour un extrait court, garde le meilleur passage :

            Une image PNG par trame, à la cadence de la vidéo, avec les jauges sur fond transparent. Les images sont regroupées dans une archive ZIP : décompresse-la avant de l'importer. Dans le logiciel de montage, importe la séquence et pose-la sur une piste au-dessus de la vidéo. Les jauges étant dessinées, elles restent nettes en 4K même depuis une vidéo HD.

            Le son ajouté dans « 1. Fichiers » est mixé par-dessus, avec ses coupes.
